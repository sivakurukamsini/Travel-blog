Travel Sri Lanka - Blog Website

This is a responsive travel blog website to showcase Sri Lankan destinations and travel stories. Users can read blogs, leave comments, and subscribe to newsletters.

The website uses HTML, CSS, Bootstrap, jQuery, PHP, and JSON. It features dynamic blog loading, category filtering, search, and a contact form. It works on mobile, tablet, and desktop devices.

You can run it locally using XAMPP or PHP server. Add blogs in data/blogs.json, comments in data/comments.json, and update styles or colors in css/style.css. This project is for learning and showcasing travel content.
